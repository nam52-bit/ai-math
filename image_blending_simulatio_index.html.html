🖼️ 두 장면 오버랩 (행렬 연산 기반 이미지 합성) 실습

두 이미지 X와 Y를 업로드하고 가중치(α)를 조절하여, 행렬 연산 R = αRX + (1-α)RY에 따른 합성 결과를 실시간으로 확인해보세요.

📐 교과서 핵심 원리

가중치 α (0 ≤ α ≤ 1)에 대하여:

  • 채널별 행렬 연산: R = αRX + (1-α)RY, G = αGX + (1-α)GY, B = αBX + (1-α)BY
  • α = 1 일 때: 이미지 X만 선명하게 보입니다.
  • α = 0 일 때: 이미지 Y만 선명하게 보입니다.
  • α = 0.5 일 때: 두 이미지 채널 값이 반반씩 섞여 비슷하게 겹쳐 보입니다.
