🧩 8×8 행렬 아다마르 곱 이미지 합성 실습 프로그램

행렬 A, B, P의 값을 직접 입력·수정하여 교과서처럼 8×8 바둑판 그림과 아다마르 곱 연산 결과(C)를 확인해보세요.

📐 교과서 핵심 원리

모든 성분이 1인 8×8 행렬을 J라 할 때, 아다마르 곱(요소별 곱셈 ∘)을 이용한 이미지 합성 공식:

C = A ∘ P + B ∘ (J - P)
